# Treinamento de Web Scraping
Treinamento para a utilização da biblioteca playwright para web scraping. Treinamento ministrado por um dos integrates da empresa junior Pi Júnior(Universidade Federal de Minas Gerais) com a finalidade de nos especializarmos ainda mais em um tipo de produto ofertado pela nossa EJ, visando sempre uma entrega de maior qualidade e profissionalismo.


### Pré-requisitos para rodar o projeto

* Node.js (versão LTS 20.x)
* Navegador (Para o projeto eh utilizado o chromium, entretanto o playwright aceita outros, como o firefox)
